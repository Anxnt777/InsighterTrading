# InsighterTrading 📈
**AI-Powered Financial Market Intelligence & Decision Support Platform**

InsighterTrading is a full-stack financial market intelligence platform combining real historical market data, technical indicators, financial news sentiment (FinBERT), multi-horizon trend classification, and explainable AI (SHAP) into an interactive research dashboard.

---

## 🏛️ System Architecture

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, TradingView Lightweight Charts, Lucide Icons.
- **Backend**: Java 17, Spring Boot 3.3, Maven, Spring Data JPA, `RestClient`.
- **AI Service**: Python 3.11, FastAPI, Pandas, NumPy, Scikit-learn, yfinance.
- **Database**: PostgreSQL 16 (with in-memory H2 fallback for zero-dependency local dev/tests).

---

## 🚀 Quick Start Guide

### 1. Prerequisites Check
Ensure the following runtimes are installed:
- **Java 17 LTS** (`java -version`)
- **Apache Maven 3.9+** (`mvn -version`)
- **Python 3.11** (`py -3.11 --version` or python 3.11 executable)
- **Node.js 20+ & npm** (`node -v`, `npm -v`)
- *(Optional)* Docker Desktop for PostgreSQL

---

### 2. Service-by-Service Startup

#### Terminal 1: Python AI Service (Port 8000)
```powershell
cd ai-service

# Create virtual environment with Python 3.11
& "C:\Users\hp\AppData\Local\Programs\Python\Python311\python.exe" -m venv .venv

# Activate virtual environment
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt

# Start FastAPI server
uvicorn app.main:app --reload --port 8000
```
*Health check*: `http://localhost:8000/health`  
*API Docs*: `http://localhost:8000/docs`

---

#### Terminal 2: Spring Boot Backend (Port 8080)
```powershell
cd backend

# Build and run unit tests
mvn clean test

# Run application (default 'dev' profile uses in-memory H2 + connects to AI service)
mvn spring-boot:run
```
*Health check*: `http://localhost:8080/api/v1/health`  
*Stock history endpoint*: `http://localhost:8080/api/v1/stocks/AAPL/history`

---

#### Terminal 3: React Frontend (Port 5173)
```powershell
cd frontend

# Install npm packages
npm install

# Start Vite dev server
npm run dev
```
Open your browser at: `http://localhost:5173`

---

## 🧪 Testing

- **Backend Tests**: `cd backend && mvn test`
- **AI Service Tests**: `cd ai-service && .\.venv\Scripts\Activate.ps1 && pytest`
- **Frontend Build**: `cd frontend && npm run build`
